📚 Менеджер документов

Библиотека СОП: исходник хранится в JSON, СОП экспортируется отдельным XLSX. Печатный TWI JI — во вкладке TWI; он не изменяет файл СОП. Номер и версия окончательно фиксируются только при публикации.

Параметры публикации

При публикации номер фиксируется окончательно: КОД.ПОРЯДКОВЫЙ_НОМЕР.ГОД ВЕРСИЯ. Сквозной номер хранится отдельно и не сбрасывается.

Библиотека СОП

Все документы имеют один из трёх статусов: Черновик, Опубликован, Архив. XLSX можно получить из любого статуса.
