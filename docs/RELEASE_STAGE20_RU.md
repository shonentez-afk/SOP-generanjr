# Stage 20 — A2: безопасный модульный экспорт XLSX

Статус: первый законченный срез пакета A2, не вся независимая архитектура. Выпуск: `releases/stage20-a2-safe-export.html`, автономный HTML для ПК, без установки зависимостей.

## Причина изменений

Stage19 по-прежнему заменяла `state.steps` результатом нормализации перед экспортом, а подготовка изображений записывала временный `_excelPhoto` в рабочие шаги. После успешного экспорта удалялся ключ локального черновика. Даже если файл Excel создавался, операция экспорта нарушала границу данных редактора.

## Исправлено

1. `core/stage20-export-snapshot.js`: `createSopExportSnapshot(state)` делает глубокую копию с поддержкой Blob, ArrayBuffer и TypedArray. Копируются шаги, FRV, чек-лист, метаданные и ключ документа. Нормализация теперь не вызывает `createEmptyStep()` и не меняет счётчик ID.
2. `photos/stage20-photo-read.js`: `readSopStepPhotoBlobForExport(step, documentId)` даёт единый способ прочитать текущие изображения/буферы, запись в IndexedDB по ключу шага или версии документа, legacy-запись. Модуль не зависит от UI или Excel.
3. `frv/stage20-measurements.js`: расчёт `computeFrv(steps=state.steps)` работает по переданным шагам и не зависит от изменений редактора во время асинхронного экспорта.
4. `excel/stage20-export.js`: Excel видит только собственный снимок; `_excelPhoto` добавляется исключительно в него, изображения проверяются до выпуска XLSX. После экспорта черновик сохраняется (XLSX — не публикация и не очистка рабочего места).
5. `src/app/stage20-parts.json` + `tools/build_stage20.py`: воспроизводимая сборка 41 упорядоченного модуля в один автономный HTML с теми же локальными ExcelJS и 60 ISO 7010. Компоновщик общий с Stage19.

## Приёмка и ограничения

CI: `python tools/build_stage19.py --verify-baseline`, `python tools/build_stage20.py --verify-release --verify-static`, `python -m unittest discover -s tests -v`, `node --check` и `python qa/stage20_browser_smoke.py`. Браузерные тесты используют настоящий Chrome и `file://`: редактирование фото, восстановление из IndexedDB, ISO, XLSX со всеми 3 изображениями, сохранность ссылок и содержимого рабочих шагов после успешной и неудачной выгрузки.

**Не изменены:** URL и логика Yandex Cloud-прокси, разрешённые модели, промпты, TWI из СОП, алгоритмы ИИ-наставника, поле ФРВ, структура IndexedDB и формат документа. Новые сетевые запросы не добавлены.

**Следующие работы:** оставшиеся контракты хранилища/версий (A2), затем независимый AI protocol (A3), история решений и защита повторной генерации TWI (A4), приёмка на реальных Windows/Excel/двух ПК/корпоративной сети (A5). Не объявлять всю архитектурную миграцию завершённой.
