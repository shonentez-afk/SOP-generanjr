## Исправления
- Стрелка выноски теперь указывает на **начальную точку перетаскивания** (выбранная деталь), а подпись располагается рядом с конечной точкой. Сама геометрия JSON не изменена.
- При выборе текстового шаблона он записывается в выделенную подпись/выноску, и операция попадает в Undo/Redo. Без выделенной подписи шаблон работает как текст для нового объекта.
- Длинные идентификаторы/слова без пробелов разбиваются по измеренной ширине, вместо выхода за границу выноски.
- Кнопки и поле canvas временно блокируются на время сохранения. Повторное сохранение невозможно; при ошибке IndexedDB редактор остаётся открытым, разметка не теряется, кнопки возвращаются. Бинарное содержимое и текст вычисляются до записи в хранилище; состояние шага обновляется только после успешной записи.
