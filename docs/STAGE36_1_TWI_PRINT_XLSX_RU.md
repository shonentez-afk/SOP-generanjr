## Назначение

Из текущего СОП и сформированного в существующей вкладке TWI плана инструктажа создаётся **отдельный автономный XLSX для печати**. В сам СОП XLSX новые вкладки не внедряются. Запросы к Yandex AI, редактор фото, ФРВ, локальные ExcelJS и пиктограммы не изменены.

## Состав Excel

1. **«Карта разбора работы» / Job Breakdown Sheet**: A4 альбомная, печать в ширину одной страницы, продолжение по высоте при необходимости, повторяемая шапка 1–10 на новых листах, номер СОП и версия, операция, участок/место, инструмент, материалы, безопасность/СИЗ, наставник и обучаемый, три смысловые колонки:
   - Важные шаги / Important Steps — фактическое действие из СОП;
   - Ключевые моменты / Key Points — `steps[].keyMoments` (первоначальные тексты без генерации);
   - Причины / Reasons Why — `steps[].reason`, не выводить причин «от себя».
2. **«План наставника»**: A4 книжная, четыре этапа TWI JI (подготовить работника, представить работу, пробное выполнение, сопровождение); все уже заполненные поля из `state.twi`, реквизиты, подписи для печати, методическая ссылка.
3. Длинные важные шаги/моменты/причины выводятся в дополнительные строки с пометкой «(прод.)»; не обрезать молча содержимое. Для многостраничной печати задаётся `fitToWidth=1`, `fitToHeight=0`, print area, print titles, поля, нумерация страниц, отключены линии сетки.
4. Экспорт проверяет отсутствие шагов и несформированный план, показывает замечания к пустым Key Points/Reasons, безопасности или устаревшему плану при изменении СОП. После явного подтверждения создаётся **печатный проект с отметкой «ТРЕБУЕТ ПРОВЕРКИ»**, без заполнения выдуманными данными.
5. Процесс экспорта делает снимок и **не изменяет** текущие СОП, TWI, фотографии, библиотеку, статусы документа. Работает из опубликованной/архивной версии как read-only.
6. Кнопка «⬇ Скачать TWI (.xlsx)» добавлена рядом с уже существующей «Сформировать план TWI»; не создавать другие разделы.

## Формат и обоснование

Метод TWI JI — важные шаги (What), ключевые моменты (How), причины (Why), обучение из 4 этапов. Не путать план JI с полной технологической картой и не объявлять об обязательном для всех предприятий унифицированном фирменном бланке: здесь печатный шаблон, согласованный с методикой, а внутренние реквизиты предприятия могут быть адаптированы.
