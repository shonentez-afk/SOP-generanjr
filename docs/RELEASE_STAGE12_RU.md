# Stage 12 — локальная ExcelJS и расширенный фоторедактор

Дата: 2026-11-18.
Ветка разработки: `feature/stage12-local-exceljs-photo-studio-20261118`.

## Ровно два функциональных изменения
1. **Локальная ExcelJS 4.4.0:** пакет `src/vendor/exceljs.min.js` из предоставленного пользователем архива ТОиР встраивается сборщиком в единый HTML вместо CDN `<script src="https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js"></script>`. MIT лицензия включена в `src/vendor/ExcelJS_LICENSE.txt` и в HTML.
2. **Расширенный редактор фотографии:** вместо простого редактора красных рамок используется отдельный исходный модуль `src/modules/photos/illustration-studio.js`, перенесённый из `js/06-photos.js` архива ТОиР. Инструменты: рамка, стрелка, нумерация, надпись, выноска, иконки, стили, выделение, Shift-множественное выделение, перетаскивание, копирование, удаление, выравнивание, распределение, отмена и очистка.

**НЕ изменено:** адрес прокси Yandex Cloud, модели, запросы ИИ, промпты, сохранение черновиков и документов, схема XLSX, ФРВ, TWI и остальные функции. Значения `APP_VERSION` и существующие ключи хранения сознательно не менялись.

## Как собрать
`python tools/build_stage12.py --verify-release`

Эта команда сравнивает полученный единый HTML с `releases/stage12-local-exceljs-photo-studio.html`. Исходный Stage 11 сохранён в `releases/stage11-photo-editor.html`.

## Проверки
- Статическая валидация JavaScript: `node --check` для обоих встроенных скриптов — PASS.
- Контракт сравнения: замена двух вставок обратно на прежние восстанавливает весь исходный HTML — PASS.
- Chromium (тестовый DOM с ограниченной навигацией из среды тестирования):
  - создание и чтение XLSX через встроенную ExcelJS при заблокированных сетевых скриптах — PASS;
  - открытие редактора, добавление рамки, стрелки, цифры и подписи, сохранение изображения в объекте шага — PASS;
  - 7 исходных вкладок доступны; необработанных JS-ошибок не было.
- Полный цикл запуска через `file://` и долговременное IndexedDB-хранилище в штатном браузере пользователя тестовая среда не позволила проверить отдельно. Хранение фото вызывает прежнюю `idbPutPhoto`, код этой функции не менялся.
- Внешние сетевые зависимости **не менялись**: Tailwind CSS и отдельные SVG-знаки безопасности по-прежнему могут требовать сеть; ИИ по-прежнему работает через исходный прокси.

## Ограничение фоторедактора
После сохранения разметка объединяется с JPEG. Повторное открытие начинает новый сеанс разметки поверх сохранённой картинки; предыдущие отдельные фигуры нельзя выделить и поправить. Исходный шаг сохраняет прежние поля. Не заявлять функцию необратимого/неразрушающего редактирования без специального изменения формата.

## При дальнейшей работе
Использовать только явные требования пользователя. Не менять ИИ-настройки в ходе фото/Excel-работ. Если что-то ещё требует внешнего Интернета, не подменять это автоматическим обновлением инфраструктуры.
