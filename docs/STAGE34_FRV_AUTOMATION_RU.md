# Stage34 — ввод замеров в программе, библиотека исследований, автоматический анализ и экспорт XLSX

**Состояние:** Stage34.1 **автоматическая приёмка PASS** (Linux и Windows, 93/93 unit, проверка конфликта М1+М2), **реальная пользовательская приёмка ещё требуется**. Основа — кандидат Stage33; **Stage32.2 остаётся принятым `main`, Stage33 по-прежнему не принят пользователем**. Не объединять Stage34 в `main` без отдельной сквозной приёмки.

## Цель

Ввод фактических действий и секунд на ПК прямо во вкладке «Анализ ФРВ». Аналитика рассчитывается без облака, ИИ только предлагает текстовые категории/улучшения. Исследование сохраняется между запусками, его можно восстановить, выгрузить Excel-отчёт и JSON-копию и из проверенных действий создать новый проект СОП. Внешних Excel-замеров нет; XLSX — только на выходе. Видео, кнопочный секундомер и сторонние XLSX/CSV-импорты **не добавлялись**.

## Реализованные функции

1. **Самостоятельная библиотека ФРВ в IndexedDB:** `src/modules/frv/stage34-library.js`; каждое исследование сохраняется отдельно под `libraryId`. Редактирование ставит запись в очередь, последняя запись считается успешно сохранённой **только после завершения транзакции IndexedDB**. Статусы: не сохранено, сохранение, сохранено, ошибка. Поддерживается отдельное исследование, открытие существующего, копия, архивация без удаления. Переключение предотвращается, если текущий документ не удалось сохранить.
2. **Восстановление JSON без перезаписи:** экспорт `FRV-1.3` содержит циклы, `observationId`, исходные секунды, пометки `до/после`, сопоставления, решения ИИ, детали. Восстановление проверяет версию, уникальность ID, допустимость времени и категорий, требует подтверждения и создаёт **новое** исследование. XLSX обратно не импортируется.
3. **Работа с замерами:** `src/modules/frv/stage34-study-model.js` — прежняя компактная таблица, повторное создание набора действий с **пустыми** секундами, переключение циклов между `До`/`После`/без группы, подтверждение сопоставления похожих действий. Фактические значения не заменяются ИИ/копированием.
4. **Автоматический анализ:** `src/modules/frv/stage34-analytics.js` — Парето по подтверждённым М1/ожиданиям (без двойного учёта), медиана/среднее/разброс (CV) для повторных действий, сравнение только **полных фактических циклов**, и разница `до/после` только с отдельным подтверждением инженером сопоставимости условий. Пустые замеры не трактуются как 0.
5. **Необязательная массовая классификация ИИ:** `src/modules/frv/stage34-study-ai.js`; ИИ предлагает `VA/M2/M1/WAIT/BREAK/OTHER`, тип потери и пояснение. Отображается отдельный список, каждую строку можно подтвердить/отклонить; изменения не применяются автоматически, фактическое действие и секунды не меняются. Используется прежний текстовый Yandex-прокси и модельные настройки.
6. **Экспорт в Excel:** `src/modules/frv/stage34-xlsx.js` — один самостоятельный XLSX с листами `Наблюдения`, `Анализ`, `Улучшения`, понятные единицы, группы циклов, пустые времена, сохранение исходных секунд, суммы и Парето, различие ожидаемого и подтверждённого эффекта, даты/операция. Локальный ExcelJS без сервера. Экспорт **не зависит** от успешно работающей IndexedDB — доступен как аварийная внешняя копия при отказе хранилища.
7. **Безопасный СОП:** `src/modules/frv/stage34-study.js` сохраняет исследование до переноса, формирует SOP по подтверждённым действиям после предпросмотра, старая версия СОП резервируется и может быть восстановлена. Ссылки `frvSource` остаются в сохраняемом черновике СОП. TWI не создаётся автоматически.
8. **Интерфейс:** обновлена **существующая** вкладка «Анализ ФРВ», без новых больших блоков. Верхняя компактная строка: новое/открыть/статус сохранения/сохранить в Excel/резервная копия JSON. В наблюдениях: повторить действия, в анализе: Парето, сравнение и ИИ-классификация. Все старые вкладки, генерация СОП и TWI оставлены.

## Архитектура и изоляция

- Ветка: `feature/stage34-frv-study-library-analysis-20261120`, **основана на Stage33**, не на `main`.
- Публикация: `src/app/stage34-parts.json` (61 модуль); `tools/build_stage34.py` собирает `releases/stage34-frv-study-library-analysis-browser-candidate.html` — единый автономный файл `file://`.
- Принятые модули `src/modules/excel/stage33-export.js`, фото Stage32.2 и ISO, оригинальный AI-прокси, TWI, библиотека СОП не менялись.
- Анализ ФРВ доступен и без ИИ; отдельная ФРВ, привязанная к готовому СОП, продолжает работать независимо.

## Принципиальные ограничения

- Данные IndexedDB привязаны к браузеру/профилю. Очистка профиля, смена ПК или иной способ запуска HTML может уничтожить/скрыть их. **Excel — читаемая внешняя копия, JSON — полноценное восстановление**. Пользователь сохраняет внешние файлы сам через стандартное скачивание Chrome/Edge. Автоматически записывать данные в произвольную папку ПК без разрешения браузера невозможно.
- Логика `до/после` не утверждает причинность; сравнение формально включается только с подписанными полными циклами двух групп и отдельным подтверждением сопоставимости.
- `SOP_ENABLE_MODEL_ROUTING` остаётся выключенным; текущий Yandex Cloud-прокси и API неизменны.
- Stage33 ещё не принята пользователем; Stage34 нельзя считать принятой автоматически по GitHub Actions.

## Stage34.1 — исправление экспорта СОП после работы в «Анализе ФРВ» (20.11.2026)

**Причина жалобы:** экспорт трёхлистного XLSX вызывает `computeFrv(exportData.steps)` для шагов **текущего СОП**. Если у шага сумма `M1+M2` превышает `durationSeconds` (например, после редактирования длительности шага, перенесённого из исследования), ранее возникало исключение `Некорректные измерения ФРВ: Шаг 6: сумма М1 + М2 больше длительности шага` и **не скачивался весь СОП**. Независимое исследование ФРВ не должно блокировать новый, другой СОП. Не маскировать фактическую ошибку измерений и не менять RAW данные автоматически.

**Внесено в Stage34 ветку (PR #29):**

1. `src/modules/frv/stage34-sop-frv-guard.js` — ранняя проверка шагов текущего СОП **до тяжёлой Excel/фотозагрузки**. Если значения несовместимы, открывается небольшое диалоговое окно с **номером, действием, длительностью, М1 и М2**. Возможности: отменить, перейти к вкладке **«ФРВ»** (фокус на проблемном шаге), или **по явному согласию скачать СОП с предупреждениями**.
2. `src/modules/excel/stage34-export.js` — последний вариант работает на **изолированном экспортном снимке**. При согласии исключает только недостоверные М1/М2 для отмеченных строк в XLSX, отключает автоматическое заполнение ВДЦ для этих строк и пишет `ФРВ не подтверждена` в **комментарий и примечание** листа ФРВ. Исходный СОП и отдельная база ФРВ **не изменяются**, листы СОП/ФРВ/Чек-лист и фотографии Stage32.2 сохраняются. Файл с исправленными **только для выгрузки** строками помечается суффиксом `_ФРВ_ПРОВЕРИТЬ.xlsx`. Если ошибка по времени шага, неподлежащая такому безопасному исключению, доступно только ручное исправление.
3. `src/modules/editor/stage34-steps.js`, `src/modules/frv/stage34-measurements.js`, `src/modules/frv/stage34-study.js` — проектная классификация М1/М2, **автоматически выведенная** из исследования на всю длительность шага, теперь помечается `autoFullStep`. При изменении проектной длительности она обновляется только для такой автоматически вычисленной классификации. **Измеренные значения `frvSource.observedTimeSec` не изменяются.** Если пользователь вручную редактирует М1/М2/ВДЦ, автоматическое слежение отключается.
4. Ни одного нового большого блока на главном экране. Разделы «ФРВ» и «Анализ ФРВ» остаются разными, TWI/AI-прокси/фоторедактор/экспорт ISO не меняются.

**Проверка:** [GitHub Actions #44679110252](https://github.com/shonentez-afk/SOP-generanjr/actions/runs/44679110252) — **PASS Linux + Windows, 93/93 модульных теста**. Новый `stage34_sop_excel_with_unrelated_research()` воспроизводит конкретную цепочку: исследование ФРВ с фактическим замером **18.5 с** → новый независимый СОП из 6 шагов → неверное распределение у шага 6 (`М1=50, М2=15, длительность=30`) → отмена, ручная правка, экспорт с предупреждениями. Проверяется настоящий XLSX, листы `СОП`, `ФРВ`, `Чек-лист оценки СОП`, `G18/J18` с пометкой `ФРВ не подтверждена`, сохранность исходных значений шестого шага и отдельного исследования.
