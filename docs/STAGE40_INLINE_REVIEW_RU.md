# Stage40 — сравнение ИИ-исправлений внутри существующей полной проверки СОП

Дата: 23.11.2026. База: принятая Stage39.1 в main. Разработка в feature/stage40-inline-ai-review-20261123, отдельный Draft PR. Основную ветку до пользовательской приёмки не менять.

## Назначение и UX

В уже существующем блоке «Полная проверка СОП» заменить дублирующий зелёный текст «Готовое исправление» на компактное сравнение **«Сейчас / После применения»** непосредственно в карточке замечания. Новых кнопок, вкладок, всплывающих окон и второго блока ИИ нет. Прежняя кнопка «Применить», действия «Оспорить»/«Отложить» и источники замечаний остаются.

Показывать сравнение только для реально применимого и локально проверенного исправления. Для обычных полей — полный текст, для КМ — итоговый список с добавленным моментом, для времени — результат в секундах. Существующие номера и переносы причин не менять.

Если поле, шаг или общие условия документа изменились со времени проверки, старое предложение **не применяется**, кнопка при обновлении списка блокируется. Повторно проверять непосредственно перед записью. Запрещено редактировать опубликованный/архивный СОП.

Индивидуальная ✨ «Причина» остаётся принятой Stage39.1: успешный ответ сразу записывается, без сравнения или дополнительного подтверждения. Новое сравнение относится только к полной проверке, где уже была кнопка «Применить».
