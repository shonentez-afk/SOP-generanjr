# Журнал результатов пилота TWI

**Статус:** пилот не подтверждён как завершённый. Не заполнять вымышленными цифрами.

Для каждого дефекта фиксировать: дату, сценарий, платформу/браузер, ожидаемое и фактическое поведение, воспроизводимость, серьёзность, ссылку на обезличенный лог/скриншот, статус исправления, версию регрессии.

## Метрики по завершении пилота

- Количество реальных аудитов и инструкторов.
- Количество мобильных устройств и пакетов импорта.
- Дубликаты/потери данных / ошибки сохранения.
- Корректность расчётов и отчётов.
- Восстановление из бэкапа.
- Блокеры промышленного запуска.
