# Stage 25 — безопасное применение предложений ИИ: СОП и ФРВ

Дата: 19 ноября 2026. Файл `releases/stage25-ai-safe-replacement.html`, 49 модулей, один автономный HTML для Chrome/Edge на ПК (`file://`). Собирается `tools/build_stage25.py`.

## Наблюдаемая проблема и решение

**СОП.** Ранее `generateSOP()` без подтверждения полностью заменял `state.steps`. Если в документе уже были внесены действия, время, требования и фотографии, их мог затереть новый AI-ответ. Stage25 сохраняет прежнюю первую генерацию, а при наличии данных открывает предпросмотр текущих и предлагаемых шагов. Три действия: оставить без изменений, добавить новые шаги (старые фото, формулировки, время и метаданные сохраняются), полностью заменить (явное предупреждение о привязанных фото). Кнопки отсутствуют вне модального окна, нет неявной записи. Stage22 guard применяется после ожидания ответа и после закрытия предпросмотра.

**ФРВ.** Раньше `frvStudyBuild()` при любом повторном вызове безусловно делал `d.cycles=[newCycle]`, удаляя прежние фактические наблюдения и measured durationSec. В Stage25 если уже есть содержательные строки, предлагается только добавить новый отдельный черновой цикл или отменить. Предыдущие строки/объекты и фактические измерения не трогаются. Даже если AI вернул `durationSec:999`, у добавленной строки будет `durationSec:null`: данные ИИ — не факт замера. Предыдущий анализ не удаляется, но помечается `analysisNeedsReview=true` при добавлении цикла; в уведомлении указана необходимость повторно проверить анализ.

**Ошибки ИИ.** `src/modules/ai/stage25-errors.js` разделяет ошибки формата/полноты, сети, таймаута, HTTP 401/403/404/408/413/429/5xx и пустого ответа. `stage25-transport.js` сохраняет `setAIStatus`, `makeTimeoutSignal`, `aiAsk`, `testAIConnection` и весь HTTP/fallback код без изменений, меняет только пользовательское представление ошибки через `diagnoseAIError`. Ретраев «за спиной пользователя» нет — повтор через прежнюю кнопку.

## Состав
- `src/modules/ai/stage25-errors.js` — `aiErrorClassify/aiUserFacingError`.
- `src/modules/ai/stage25-preview.js` — общий безопасный диалог решения, отдельные предпросмотры СОП/ФРВ и проверка реального содержания.
- `src/modules/ai/stage25-generate-sop.js` — генерация с отменой/добавлением/полной заменой.
- `src/modules/frv/stage25-study-ai.js` — сохранение старых измерений, отдельный AI-цикл.
- `src/modules/ai/stage25-transport.js` — неизменный сетевой контракт, новая обработка ошибки.
- `src/app/stage25-parts.json`, `tools/build_stage25.py` — детерминированная сборка 49 JS-модулей и локальных ресурсов в один HTML.

## Проверки
`python tools/build_stage25.py --verify-release --verify-static`, `python -m unittest discover -s tests -v`, `node --check` runtime и `python qa/stage25_browser_smoke.py` в настоящем Chrome через `file://`. QA запускает все текущие проверенные функции и отдельно тестирует первую генерацию, отмену, добавление, замену, фото, сохранение замеренных данных, неполный/невалидный JSON, изменение документа во время предпросмотра и классификацию ошибок. Никаких реальных сетевых запросов к Yandex в автоматическом тесте; реальная Windows/корпоративная сеть/прокси тестируются отдельно.

Программа находится в стадии разработки: миграции исторических установок не выполняются. Отдельный конструктор TWI не создаётся, TWI формируется из СОП, ФРВ необязательна. Полная A3/A4/A5-приёмка ещё не закрыта.
