# Stage 19: исходный код разложен по функциональным модулям

Stage 19 — завершённый структурный этап A1 с нулевым изменением поведения, но НЕ весь архитектурный пакет A.

- Основной JS Stage 18 перенесён в 27 файлов src/modules/*/stage19-*.js, порядок — src/app/stage19-parts.json.
- Оболочка в src/app/stage19-*.html; ExcelJS 4.4.0 и лицензия переиспользуются из src/vendor, 60 локальных ISO 7010 из src/assets/safety/iso7010-part01..07.json.
- tools/build_stage19.py собирает releases/stage19-modular-runtime.html непосредственно из этих файлов без последовательного запуска прежних Stage 12–18 patch-builders.
- Команды: python tools/build_stage19.py --verify-baseline; python tools/build_stage19.py --verify-release; python -m unittest discover -s tests -v.
- На первом этапе A1 собранный HTML обязан совпасть с Stage 18 символ в символ: изменилось расположение исходников, а не алгоритмы или пользовательский интерфейс.
- Пользователю остаётся один автономный HTML, двойной клик в Chrome/Edge на ПК; без внешних файлов или сервера.

## Что осталось по A2–A5

- Сейчас исходники разделены физически, но функции ещё используют прежнее общее лексическое окружение одного script и глобальное состояние. Называть это полностью независимыми модулями пока нельзя.
- Далее: контракты core/state, shared/media, photo/repository, Excel/storage, AI transport/protocol/tasks/presenter; защита рабочего state и фотографий от побочных эффектов; безопасные предложения ИИ и протокол ошибок.
- Сохранение по документу/версии истории наставника с миграциями; предпросмотр повторной генерации СОП/ФРВ.
- TWI только автоматически из текущего СОП, затем при желании ручная коррекция. При повторной генерации сохранить/подтвердить замену уже изменённого TWI. ФРВ необязательна.
- Настройки Yandex Cloud-прокси, модели, промпты, фото, XLSX, ФРВ, TWI, документы и все форматы сохранены без изменения.

## Подтверждение

tests/test_stage19.py и .github/workflows/stage19.yml проверяют идентичность Stage18/Stage19, Node JS syntax, реальные Chrome file:// сценарии фотографий/Excel и ответов наставника.
Windows, штатный Excel, сетевая папка на двух ПК и рабочий Yandex Cloud-прокси требуют отдельной ручной приёмки.
