## Исправленная проблема
Раньше каждое нажатие «Сформировать TWI» выполняло `state.twi={...}` и заменяло все поля, даже если работник после предыдущей генерации вручную уточнил формулировки. Дополнительно при генерации терялись значения `trainer` и `trainee`. Некорректный, пустой или неполный ответ ИИ мог очистить заполненный план.

## Новое поведение
1. **Первый TWI:** формируется автоматически из текущего СОП. Никакой анкеты, обязательного ФРВ или отдельного мастера. `trainer` и `trainee` сохраняются, если уже указаны.
2. **Происхождение полей:** `src/modules/twi/stage24-merge.js` фиксирует `generatedBaseline` (полученный текст каждого поля последнего AI-результата) и `sourceSignature` по конкретным исходным данным СОП. При последующих правках значения сравниваются с предложением ИИ, чтобы отличать пользовательские изменения.
3. **Повторная генерация:** при отличиях `stage24-preview.js` показывает модальное сравнение «Сейчас / Предложение ИИ» для изменившихся полей. Отмена не меняет документ. Значения, изменённые пользователем, и предложения очистить существующий текст **не отмечаются для применения**. Для их замены нужно самостоятельно установить галочку. Ничего не записывается до «Применить выбранные».
4. **Обычные обновления:** поля, которых пользователь не касался, предварительно отмечены к применению. Выбор действует отдельно для каждого поля, без перезаписи соседних ручных значений.
5. **Актуальность:** если после генерации поменялись шаги, Key Points, Reasons Why, критерии результата, условия безопасности, исполнители или иные входные данные, на вкладке TWI видно предупреждение о необходимости проверки. Это информативная отметка, без автоматического изменения TWI.
6. **Защита от опоздавшего ответа:** перед первым применением и после модального сравнения используется Stage22 `aiGuardCanApply({twi:true})`. Если за время ожидания изменился СОП/TWI, результат отвергается.
7. **Неполный AI-JSON:** `src/modules/ai/stage24-task-response.js` вводит `aiReadTaskObject` для генерации СОП/проверки и `aiReadTwiPlan` для четырёх этапов TWI. Если нет полезного содержимого хотя бы в одном этапе, текущий TWI не изменяется. Прежние TWI поля и частотный псевдоним `frequency` принимаются при разборе. Ошибки формата дают понятное сообщение.
8. **Без изменений:** URL Yandex Cloud-прокси, список моделей, параметры запросов, системные промпты, сетевой транспорт и fallback, ExcelJS, 60 локальных знаков ISO 7010, фото/разметка, ФРВ, формат XLSX, базовая схема хранилища и способ запуска файла.

## Исходники
- `src/modules/ai/stage24-task-response.js` — AI JSON-контракт.
- `src/modules/ai/stage24-generate-sop.js` и `stage24-review-task.js` — переключены на общий декодер без изменений AI-промптов.
- `src/modules/twi/stage24-merge.js` — подпись источника и безопасное объединение полей.
- `src/modules/twi/stage24-preview.js` — доступный пользователю предварительный просмотр и выбор.
- `src/modules/twi/stage24-from-sop.js` — единственная текущая реализация генерации TWI.
- `src/app/stage24-parts.json` и `tools/build_stage24.py` — воспроизводимая сборка автономного HTML.

## Автоматическая приёмка
`python tools/build_stage24.py --verify-release --verify-static`, `python -m unittest discover -s tests -v`, `node --check` полного runtime, `python qa/stage24_browser_smoke.py`.
Браузерный тест без доступа к реальному proxy покрывает: первый SOP→TWI, сохранение инструктора/обучаемого, сохранение ручных правок, подпись СОП, сравнение, отмену, выбор по полям, отказ от пустого/невалидного JSON, устаревшее состояние во время модального окна; затем запускает сквозные регрессии Excel/фото/ISO/библиотеки/наставника/ФРВ. GitHub Actions в `.github/workflows/stage24.yml` должен пройти до объединения.

## Границы
Мы разрабатываем программу с нуля; миграции прежних пользовательских установок не выполняются. Старые Stage — контрольные точки против регрессий. Не объявлять все A3/A5 завершёнными: остаются централизованная классификация сетевых ошибок/timeout/fallback, защитный предпросмотр AI-перезаписи существующих СОП/ФРВ и ручная приёмка Windows/корпоративной сети/живого Yandex Cloud.
