# Stage 17 — исправление спора с ИИ-наставником (18.11.2026)

Исправлена ошибка в «Оспорить» / «Отправить наставнику»: вместо ответа программа показывала `Unterminated fractional number in JSON at position 2`.

## Причина
Обработчик `sendDispute` сразу выполнял `JSON.parse(extractJson(await aiAsk(...)))`. Незавершённый или текстовый ответ модели вызывал исключение, которое через `diagnoseAIError` выводилось как реплика наставника. Нельзя утверждать, что корень неполного ответа — именно модель или прокси, пока нет реального тела сетевого ответа.

## Исправлено
- Устойчивый разбор ответа: валидный JSON и структурированные поля проверяются.
- При синтаксической ошибке повтор того же запроса один раз, без изменения исходного промпта, модели, прокси или параметров.
- Полный ответ обычным текстом может отображаться как комментарий (вердикт остаётся `keep`; замечание не снимается).
- Если оба ответа повреждены, появляется системное сообщение, не маскирующееся под слова наставника. Исходное замечание не изменяется; аргумент остаётся в поле для повтора.
- Повторная отправка после системного сбоя не дублирует аргумент в истории, системные ошибки не направляются обратно модели как речь наставника.
- Ошибки сети, авторизации и лимитов не повторяются как ошибки JSON.
