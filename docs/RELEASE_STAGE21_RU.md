# Stage 21 — A2: сохраняемая история проверки СОП

Дата: 19.11.2026. Выпуск: `releases/stage21-review-history.html` (один автономный HTML для ПК Chrome/Edge через `file://`).

## Проблема
В Stage20 `collectDraft()` и `docSnapshot()` не сохраняли массив `reviewIssues`, итог `reviewSummary` и диалоги `thread`. `applyDraft()` вообще очищал замечания. После восстановления черновика, открытия документа из библиотеки или переноса версии пользователь мог потерять обсуждение с ИИ-наставником.

## Реализация
1. Новый `src/modules/documents/stage21-review-state.js`: `captureSopReviewState()`, `restoreSopReviewState()`, `renderRestoredSopReviewState()`. Сериализуются исключительно пользовательские данные, а не запрос в процессе (`pending`). Глубокие копии, безопасные ограничения на размер истории, никаких сетевых вызовов.
2. Новые исходники `stage21-draft.js` и `stage21-db.js`: необязательное `reviewState` добавлено в локальный черновик и snapshot библиотеки. Старые записи открываются без миграции БД; прежний `deferredIssueKeys` поддерживается.
3. `stage21-library.js`: при открытии СОП восстанавливается именно его проверка, при создании чистого СОП она очищается; новая редакция опубликованного СОП получает пустую текущую проверку, не удаляя историю предыдущей опубликованной редакции.
4. Версионированные переносимые копии автоматически получают поле `reviewState` внутри прежнего `constructor`; прежняя внешняя структура и целостность SHA-256 остаются как раньше. Новых objectStore и ключей нет.
5. `tools/build_stage21.py` и `src/app/stage21-parts.json`: автономный HTML из 42 модулей, прежняя локальная ExcelJS, 60 ISO 7010. `tests/test_stage21.py`, `qa/stage21_browser_smoke.py` и `stage21.yml` обеспечивают сборочную и регрессионную проверку.

## Проверки и ограничения
Для приёмки требуется: `python tools/build_stage21.py --verify-release`, `--verify-static`, `python -m unittest discover -s tests -v`, `node --check` JS, `python qa/stage21_browser_smoke.py` (реальный Chrome `file://`, offline, IndexedDB/Excel/фото/наставник).

При повторном полном запуске проверки наставника новая проверка по-прежнему заменяет прежний текущий список замечаний — история нескольких проверок пока не архивируется. Не заявлять завершение A2/A3/A4/A5. Ручная приёмка Windows, реального Excel, сетевого диска и Yandex Cloud-прокси ещё необходима. Не менялись модели, промпты, транспорт, TWI/ФРВ и мобильные сценарии.
