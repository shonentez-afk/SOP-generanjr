## Уточнение рабочего сценария TWI — 19.11.2026 (пожелание владельца проекта)
- **TWI в Конструкторе СОП создаётся автоматически ИИ из уже составленного СОП.** Порядок: создать/отредактировать СОП → нажать генерацию плана TWI → при необходимости вручную подправить полученный план. Не проектировать параллельный сценарий самостоятельного составления TWI с нуля или обязательное ручное заполнение TWI.
- Текущий `generateTwiPlan()` действительно передаёт модели поля `operation/executor/workplace/safety` и шаги `action/keyPoints/reason/successCriteria/decisionPoints` из `state.steps`, затем показывает сгенерированные поля; `htmlToTwi()` предназначен для последующей ручной корректировки. Это подтверждено кодом Stage 18.
- **Улучшать именно производный сценарий:** TWI связан с источником СОП/его редакцией; при правке СОП показать, что план обучения может устареть; предложить его обновление; сохранить либо отдельно согласовать уже внесённые пользователем поправки; не перезаписывать исправленный TWI без предупреждения и подтверждения. При первой генерации не требовать ручного заполнения.
- В плане развития пакет C читать как: **ФРВ (при наличии) → СОП → автоматически сгенерированный TWI → необязательная ручная корректировка.** ФРВ не является обязательным условием генерации TWI; отдельный проект TWI Audit RC1 не смешивать с TWI-планом в Конструкторе СОП.
- Источник решений: `docs/AI_CAPABILITIES_MODULARIZATION_AUDIT_20261119_RU.md`, раздел об уточнённом TWI. Это документация, приложение Stage 18 и настройки ИИ не менялись.
