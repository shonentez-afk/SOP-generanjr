Обзор Stage39

Система работает на ПК как один автономный HTML, собранный из 67 JavaScript-модулей. Для генерации текста используется внешний AI-прокси Yandex Cloud. Документы и фотографии сохраняются локально; обмен через сетевую папку необязателен.

Главный поток: описание работы → генерация/редактирование СОП → проверка → экспорт корпоративного XLSX либо формирование TWI → экспорт TWI XLSX.

ФРВ: отдельное исследование, которое можно передать в новый проект СОП только после подтверждения.

Выберите узел на схеме для подробностей.

Основа: SOP-generanjr, зафиксированная ревизия. Открыть подробную карту запросов/ответов ИИ. Визуализация подготовлена отдельно; это совместимый по содержанию просмотрщик, а не экспорт, сформированный CLI Archify. Исходник в нативном формате Archify.
