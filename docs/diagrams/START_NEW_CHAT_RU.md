## Точные изменения архитектуры Stage41

1. **Stage39.1:** индивидуальная ✨ «Причина» `stage391SafeReasonField` проверяет основание WHY, нормативы и параметры, допускает ограниченную повторную попытку; валидный ответ напрямую обновляет одно поле `steps[].reason`, **без** отдельного окна «Было → Стало» и **без** кнопки повтора КМ.
2. **Stage40:** встроенное сравнение «Сейчас / После применения» **только внутри карточки полной проверки**, с защитой устаревших исправлений и ручных правок.
3. **Stage41:** `src/modules/ai/stage41-quality.js` оборачивает `aiAsk` для **только** `generate_sop`, `review`, `twi_generate` и фильтрует только точные доказанные дубли AI-fix. Не меняет исходный transport, `edit_reason`, `edit_km`, FRV, corporate XLSX, ISO, фото.
4. **Наставник:** штатная кнопка логики работает через `stage28ReviewLogic() → reviewEntireSOP()`. `stage27ReviewLogic()` сохранена как функция в исходниках, но **не отдельный штатный вызов UI**. На схеме не показывать её как второй реальный запрос.
5. **TWI создаётся только из СОП**, не напрямую из ФРВ; реальные замеры и RAW нельзя заменять ИИ-предложениями.
