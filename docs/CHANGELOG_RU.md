# История версий

## Stage 13 — неразрушающая фоторазметка (2026-11-18)
- Отдельное хранение исходного JPEG/Blob, фигур JSON и экспортируемого JPEG.
- Повторное открытие, удаление и изменение ранее сохранённых фигур.
- Фотоизображения копируются в IndexedDB с ключом документа и шага при сохранении/создании новой версии.
- Изменения ограничены фотографиями и местами их интеграции. ИИ, прокси и ExcelJS без изменений.
- Полный отчёт и ограничения: `docs/RELEASE_STAGE13_RU.md`.



## Stage 12 — локальная ExcelJS + Photo Studio (2026-11-18)
- ExcelJS 4.4.0 из архива ТОиР встроена в единый HTML вместо CDN, сохранена лицензия MIT.
- Расширен редактор фотографий шага: рамка/стрелка/цифра/подпись/выноска/значки, стиль, выделение, перетаскивание, копирование и выравнивание.
- Созданы воспроизводимая сборка и проверки только этих изменений.
- Настройки ИИ, прокси, модели, другие модули и форматы сохранены без изменений.
- Ограничения и регрессионные проверки: `docs/RELEASE_STAGE12_RU.md`.


## Stage 11 + фоторедактор — baseline (2026-11-18)
- Зафиксирован конструктор SOP Stage 11.
- В предыдущем этапе встроен редактор фото шага с выделением красными прямоугольниками, отменой и очисткой разметки.
- Код из предыдущего чата сохранён в `releases/stage11-photo-editor.html`.
- **Новых изменений в работе приложения при переносе в репозиторий не вносилось.**
- Сборка из модулей и полная браузерная регрессия ещё требуют проверки.
