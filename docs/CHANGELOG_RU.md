# История версий

## Stage 15 — локальные пиктограммы ISO 7010 (2026-11-18)
- 60 знаков безопасности встроены в итоговый HTML в виде исходных SVG, все 60 доступны без загрузки из интернета.
- Убраны очереди сетевой подгрузки и зависимость от внешних изображений при XLSX-экспорте: экспорт использует локальный Canvas PNG.
- Добавлен воспроизводимый сборщик, регрессионные тесты и реальный Chrome-тест `file://` со всеми сетевыми запросами заблокированными.
- Занесены происхождение SVG, MIT-лицензия пакета, ссылки на исходные изображения Wikimedia; лицензия включена в HTML.
- ИИ, Yandex-прокси, ExcelJS, ФРВ, TWI и редактор фото без изменений; Stage 14 остаётся нетронутым.
- Релиз: `releases/stage15-local-iso7010-icons.html`; документ `docs/RELEASE_STAGE15_RU.md`.



## Stage 14 — исправление UX/UI и сохранности данных, версия для ПК (2026-11-18)
- Фото из XLSX сохраняются в IndexedDB; отклонение черновика не удаляет фото библиотеки.
- Полные переносимые JSON/сетевая папка теперь включают исходные фотографии, разметку и JPEG. Добавлен импорт JSON.
- Полностью локальная CSS Tailwind 4.1.10 (ExcelJS 4.4.0 сохранена).
- Backspace в поле подписи, кнопка нового СОП, очистка TWI, баннер блокировки, ARIA и уведомления исправлены.
- Прямая автоматическая синхронизация исправлена (`manual`), резервные файлы не импортируются как активные СОП.
- Объём: ПК. Телефон намеренно исключён. ИИ/прокси и XLSX-формат без изменений.
- Исполняемый HTML: `releases/stage14-desktop-ux-data-integrity.html`. Отчёт: `docs/RELEASE_STAGE14_RU.md`.



## Stage 13 — неразрушающая фоторазметка (2026-11-18)
- Отдельное хранение исходного JPEG/Blob, фигур JSON и экспортируемого JPEG.
- Повторное открытие, удаление и изменение ранее сохранённых фигур.
- Фотоизображения копируются в IndexedDB с ключом документа и шага при сохранении/создании новой версии.
- Изменения ограничены фотографиями и местами их интеграции. ИИ, прокси и ExcelJS без изменений.
- Полный отчёт и ограничения: `docs/RELEASE_STAGE13_RU.md`.



## Stage 12 — локальная ExcelJS + Photo Studio (2026-11-18)
- ExcelJS 4.4.0 из архива ТОиР встроена в единый HTML вместо CDN, сохранена лицензия MIT.
- Расширен редактор фотографий шага: рамка/стрелка/цифра/подпись/выноска/значки, стиль, выделение, перетаскивание, копирование и выравнивание.
- Созданы воспроизводимая сборка и проверки только этих изменений.
- Настройки ИИ, прокси, модели, другие модули и форматы сохранены без изменений.
- Ограничения и регрессионные проверки: `docs/RELEASE_STAGE12_RU.md`.
