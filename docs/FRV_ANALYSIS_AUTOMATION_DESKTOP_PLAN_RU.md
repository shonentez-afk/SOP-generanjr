# План автоматизации «Анализа ФРВ» — ввод в программе, выгрузка для сохранности

**Обновлено 20.11.2026 по уточнению пользователя.** Это проектный план будущего пакета после Stage33, не реализованная функция. Пользователь пояснил: на заводе **замеры в Excel не ведутся**, поэтому внешние таблицы для импорта отсутствуют. Замеры должны **вводиться непосредственно в «Анализе ФРВ»**, сохраняться в программе, а по желанию экспортироваться в Excel, чтобы иметь отдельную копию и не потерять данные. XLSX — **результат работы**, не исходный источник данных. **Импорт XLSX/CSV, вставка чужих таблиц, видеоанализ и кнопочный хронометраж исключены** из плана.

## 1. Правильный маршрут

**Войти в «Анализ ФРВ» → вручную записать фактические действия и секунды → сохранить исследование → автоматически посчитать показатели → (необязательный текстовый ИИ) классификация и предложения → инженер подтверждает улучшения → по желанию формирует новый проект СОП.**

Обычный раздел «ФРВ» при готовом СОП остаётся самостоятельным. Путь «Анализ ФРВ → новый проект СОП» сохраняется, но не становится обязательным. TWI генерируется отдельно из СОП, без прямой связи с ФРВ.

## 2. Главное: сохранность исследований

- **Автоматическое локальное сохранение введённых наблюдений** при изменениях (без отдельного нажатия после каждой строки), с понятным индикатором «Сохранено / Есть несохранённые изменения / Ошибка сохранения». Не считать состояние надёжно записанным, пока IndexedDB/локальное хранилище не подтвердило запись.
- **Несколько отдельных исследований** в локальной библиотеке/архиве: название операции, участок, дата/обновление, статус, число циклов. Можно закрыть программу и открыть исследование снова. Не смешивать с черновиком текущего СОП и не перезаписывать другое исследование при создании нового.
- **Защита от случайного удаления и переключения**: черновики, восстановление последней успешной записи, проверка перезаписи, копия перед разрушительным действием; если хранилище недоступно, вывести ошибку и предложить экспорт.
- **Экспорт XLSX по кнопке «Сохранить в Excel»** как понятная человеку внешняя копия. Предложенная структура: листы **«Наблюдения»** (все действия, циклы, реальные секунды, тип затрат, примечания), **«Анализ»** (итоги/доли/средние/Парето по подтверждённым замерам) и **«Предложения»** (необязательные рекомендации и решения инженера, явно отдельно от фактов). Включить дату, номер/название исследования и единицы измерения. Не изменять исходное исследование при экспорте.
- **Экспорт машиночитаемой резервной копии JSON** оставить рядом с XLSX: Excel — для чтения, печати и независимого хранения; JSON — для восстановления **всех** полей, исходных ID, источников, циклов и промежуточных решений, если потребуется перенести исследование в другой браузер/на другой ПК. Поддержка безопасного восстановления JSON — отдельная часть пакета, не импорт замеров из стороннего Excel.
- **Локальные данные браузера могут быть очищены** вместе с профилем/данными сайта или файлом HTML: нельзя обещать, что единственное автосохранение гарантирует сохранность. Предусмотреть подсказку о периодическом выгружении внешней копии (XLSX + JSON) в выбранную пользователем папку. Приложение не может молча записать файл в произвольную папку на диске без разрешения.

## 3. Автоматизация анализа по введённым данным

1. **Подсказки заполнения без выдуманных секунд:** из краткого описания текстовый ИИ может предложить перечень действий как **незамеренные** строки; оператор сам вписывает измеренное время. Сведения об источнике и факте подтверждения сохраняются.
2. **Удобство ручного ввода:** компактные колонки «Действие / время, сек / категория / комментарий / перемещение», копирование и повтор действий между измеренными циклами **без копирования времени как нового факта**. Дополнительные инженерные поля — в раскрываемом блоке.
3. **Сопоставление циклов:** подсказки по одинаковым/похожим действиям, сравнение длительности, медиана, среднее, разброс и отклонения. Различные операции не склеивать автоматически по одному названию.
4. **Расчёты без ИИ:** ВДЦ, М1, М2, ожидания/перерывы, доли, самые длительные действия, Парето потерь, нестабильные операции. Измерение `null` не превращать в `0`. Оценку «до/после» делать только по реальным двум наборам данных.
5. **Необязательный текстовый ИИ:** предлагает классификацию, вероятные причины и 3–5 улучшений по введённым фактам. Изменения применяются только после проверки инженера. ИИ не меняет исходное действие/секунды и не назначает норматив без подтверждения.
6. **Проект СОП:** преобразование утверждённых действий в новый редактируемый СОП после предпросмотра и подтверждения; ссылка на исходные измерения сохраняется; существующий СОП защищён резервной копией.

## 4. Предлагаемый интерфейс без новых больших блоков

Оставить **одну вкладку «Анализ ФРВ»** и действующую структуру Stage33. На верхней панели: **«Новое исследование» · «Открыть исследование» · «Сохранено» · «Экспорт Excel»**. Рядом в меню резервного копирования — **«Сохранить копию JSON / Восстановить копию»**. Ни одного блока «Импорт XLSX/CSV» или «Живой замер».

Под ними — компактная таблица наблюдений, автоматическая сводка, необязательные предложения ИИ и «Подготовить проект СОП».

## 5. Следующий крупный пакет и QA

**После пользовательской приёмки Stage33**, одним крупным пакетом реализовать: надёжную локальную библиотеку/автосохранение ФРВ, повторное открытие исследований, экспорт отдельного XLSX и JSON с обратным восстановлением, автоматические аналитические показатели/Парето и необязательную текстовую ИИ-классификацию. Не пересоздавать уже готовые расчёты Stage33 и не усложнять интерфейс.

Проверить: закрытие/повторное открытие HTML, несколько исследований, отключённое/заполненное хранилище, отсутствие потерь при отмене, пустые времена, много циклов, названия/единицы/целостность XLSX, восстановление JSON с совпадающими исходными наблюдениями, совместимость редактора СОП/TWI и принятого экспорта XLSX-фотографий Stage32.2. Проверки Linux и Windows, затем пользовательская приёмка на настоящем ПК.

## 6. Не менять

Принятую Stage32.2 в `main`, отдельно проверяемую Stage33 (PR #28), Excel-фотографии/ISO, локальную ExcelJS, настройки Yandex Cloud-прокси и `SOP_ENABLE_MODEL_ROUTING` (выключен). Не использовать видео, таймер и импорт чужих Excel-замеров без новой прямой задачи.
