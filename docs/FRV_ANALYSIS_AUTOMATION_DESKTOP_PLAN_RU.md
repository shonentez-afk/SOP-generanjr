# План дальнейшей автоматизации «Анализа ФРВ» для настольного конструктора СОП

Дата: 20.11.2026. **Только проектный план, Stage34 не реализован.** Пользователь уточнил: приложение только для ПК; хронометраж по кнопкам бессмысленен; используемая модель ИИ **не поддерживает видео**. Исключить оба направления: **анализ видеозаписей** и **кнопочный живой таймер**. Не предлагать их снова без нового явного запроса.

## Исходная задача

Сначала наблюдаем и изучаем работу, затем (по желанию) создаём оптимизированный СОП из подтверждённых данных. Stage33 — самостоятельный «Анализ ФРВ» и создание нового СОП; обычная «ФРВ» для уже готового СОП остаётся отдельной вкладкой. Текущая Stage33 в PR #28 — кандидат, CI PASS, пользовательская приёмка ещё ожидается. Stage32.2 — принятая версия в `main`.

## Наиболее полезная автоматизация **без видео, таймера и нового ИИ**

1. **Импорт замеров:** Excel XLSX и CSV, вставка табличных строк из буфера обмена, а также свободно описанные наблюдения. Использовать уже поставляемую локально ExcelJS для XLSX. Настраиваемое сопоставление колонок: действие, длительность, единицы (сек/мин), цикл, тип времени, примечание, исполнитель. Предпросмотр распознанных строк до принятия; неполные записи и неоднозначные единицы помечать, а не угадывать. Сырые импортированные значения и сведения об источнике неизменны.
2. **Подготовка действий из обычного текстового описания:** уже есть Stage33 предложение ИИ; усовершенствовать распознавание последовательности, удаление дубликатов и группировку синонимов. Предлагать изменения в отдельном черновике, подтверждение пользователем; **время не придумывать** и не считать предложение реальным замером.
3. **Сопоставление повторных циклов:** сначала точные/нормализованные совпадения, затем подсказки ИИ по неоднозначным названиям. Каждое сопоставление — предложение, которое можно отклонить. Не объединять различные технологические действия из-за похожих названий; поддерживать неодинаковые и неполные циклы.
4. **Автоматические количественные расчёты:** ВДЦ/М1/М2 и отдельно ожидания/перерывы; среднее, медиана, размах, CV только по подтверждённым данным; рейтинг самых дорогих операций, Парето потерь, выявление нестабильных и повторяющихся операций, сравнительный отчёт «до/после» только при наличии двух реальных наборов замеров.
5. **ИИ-классификация и рекомендации:** по текстовым действиям ИИ предлагает ценность/тип потери/причину и 3–5 инженерных улучшений. Никакого автоматического утверждения классификации и никакого изменения сырого действия/секунд; пометка уверенности, объяснение и проверка человеком. ИИ на текущем текстовом провайдере и прокси, без замены настроек и моделей.
6. **Подготовка проекта СОП:** подтверждённые действия и улучшения преобразуются в редактируемый проект шагов с источниками и фактическими временами; инженер подтверждает порядок, ключевые моменты, безопасность и **проектное** время; прежний СОП не перезаписывается без предпросмотра и возможности восстановления. TWI продолжает формироваться только отдельно из готового СОП.

## Предлагаемый экран (без новых больших вкладок)

Сохраняем единую вкладку «Анализ ФРВ» Stage33. Вверху только три способа заполнения: **«Ввести вручную» · «Вставить таблицу» · «Импорт XLSX/CSV»**. Далее один список наблюдений, рассчитанная сводка, необязательная кнопка **«Найти улучшения с ИИ»** и блок **«Подготовить СОП»**. Подробные классификаторы/циклы/источники — в «Подробнее». Не создавать отдельные панели «AI-подготовка», «AI-проверка», «AI-применение» для каждого шага.

## Порядок следующего крупного пакета

- После приёмки Stage33 одним пакетом добавить: импорт XLSX/CSV и вставку таблицы, контроль входных данных, нормализацию/сопоставление действий и циклов, автоматический анализ потерь и компактный отчёт, рекомендации текстового ИИ по подтверждённым данным. Не затрагивать импорт СОП/фото и принятый экспорт XLSX Stage32.2.
- Проверки: таблицы в произвольном порядке колонок, локаль с десятичной запятой, секунды/минуты, дубликаты, пропуски времени, несколько циклов и отдельные ожидания, негативные/аномальные длительности, исходные RAW + связность этапов, сохранение/восстановление, полноценная регрессия генерации СОП/TWI и XLSX-фото.

## Запреты/ограничения

- **Не реализовывать видеоанализ или кнопочный хронометраж.**
- **Не менять существующий Yandex Cloud-прокси и флаг `SOP_ENABLE_MODEL_ROUTING` (выключен).** Не предполагать, что текущий ИИ поддерживает видео, аудио или OCR.
- Без вымышленных времени, циклов и нормативов. Необязательная автоматика должна быть проверяема и отменяема.
- Принятая Stage32.2 и кандидат Stage33 не менять на основании одного планового обсуждения.
