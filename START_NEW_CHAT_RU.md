## Статус проекта

Разработан автономный TWI Job Instruction L1 audit RC1 для ООО «Завод ТЕХНО». Один HTML запускается в Chrome/Edge, локальная база `twi_data.json` schemaVersion 3, мобильная HTML-форма, экспорт/импорт, отчёты и опциональная AI Cloud Function. Чек-лист 4 шага, 20 критериев; версии v1/v2 не смешиваются. L2/L3 — контрольные даты, нет утверждённых L2/L3 чек-листов.

Проведён предрелизный программный QA, но не выполнен полный реальный пользовательский пилот. Известные ограничения: одна JSON база — один писатель; mobile localStorage; ручные backups; открытый URL Cloud Function требует защиты.
