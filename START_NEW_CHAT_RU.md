## Что это за приложение

Локальный TWI Job Instruction L1 audit для ООО «Завод ТЕХНО». HTML напрямую в Chrome/Edge, JSON-база через File System Access API, при необходимости Yandex Cloud Function для AI аналитики. Схема базы 3. Оригинальные 4 шага / 20 критериев (7+4+4+5), L2/L3 — только календарный контроль, цифровые чек-листы не утверждены.

## Реализовано к RC1

- Чек-лист L1, справочники инструкторов/тренеров, журнал и управляемое изменение/аннулирование с логом.
- Дашборд KPI, матрица инструктор×критерий, тренды, Pareto, повторные отклонения и профиль риска.
- Корректирующие мероприятия, статусы и оценка эффективности после повторных аудитов.
- Каскад контрольных сроков L2 (+30 дней) и L3 (+60..90 дней).
- Отчёты руководству, тренеру, инструктору, печать и HTML-экспорт.
- Опциональная AI-интерпретация на локально вычисленных фактах.
- Мобильный автономный HTML, очередь/архив, экспорт и импорт с защитой от дублей.
- Резервное копирование/восстановление JSON, журнал импорта.
- Версии чек-листа v1/v2: черновик/активация/архив; исторические аудиты остаются привязаны к исходным версиям, аналитика разных версий не смешивается.

## RC1 предрелизная проверка

Синтаксис обоих JS-блоков и index.py, DOM ID, smoke init, два поколения чек-листов, миграция реальной базы версии 2 (3 аудита, 0 ошибок целостности), отчёты, AI contract, импорт, мобильный цикл, backup/restore и fake Cloud Function проверены. Список исправлений — в `release/RC1/PRERELEASE_QA_RU.txt`.

## Известные ограничения

- Единственный JSON — один записывающий экземпляр, не мультипользовательская база.
- URL Cloud Function сам по себе не защищён; CORS не равен авторизации.
- Мобильная незагруженная очередь — в localStorage браузера.
- Нужны реальные кликовые тесты на рабочих Chrome/Edge и корпоративных телефонах.
- Backups ручные; L2/L3 чек-листов нет; аналитика разных версий раздельна.
